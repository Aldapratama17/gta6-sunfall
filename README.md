Sunfall City is an original open-world crime game built for make.fun's "Make GTA 6" bounty ($1,666 USDC). It's a top-down 2D canvas game written in vanilla JavaScript with all art drawn procedurally in code — no external assets, no borrowed names. Explore a sprawling city with distinct districts, steal and drive cars, evade a dynamic police response, play through a short story with named characters, and survive on-foot combat. The game runs offline in desktop Chrome with no build step.
